About INOUTX

About the System

IN/OUT X is an AI-Based College Transport Management System designed to automate and simplify college bus monitoring at KRCT and KRCE campuses. The system uses Artificial Intelligence, computer vision, YOLOv8 vehicle detection, vehicle tracking, and PaddleOCR-based number plate recognition to identify and verify registered college buses through live CCTV cameras. Its First Virtual Line Crossing Concept determines whether a bus is entering or exiting based on which configured virtual line it crosses first. MongoDB Atlas stores registered bus information and verified vehicle movement records, enabling centralized monitoring and efficient report management. From a non-technical perspective, IN/OUT X reduces the need for manual vehicle monitoring and paper-based records, helping college authorities track bus movements more efficiently and reliably. By automating vehicle identification, entry and exit classification, and recordkeeping, the system saves time, reduces human error, and improves campus transport management. Combining intelligent automation with a user-friendly monitoring interface, IN/OUT X aims to provide a smarter, more organized, and dependable transportation monitoring solution for educational institutions.

System Insights

Frequently Asked Questions

Technical clarifications regarding YOLO detection, virtual lines, and college bus monitoring.

How does the First Virtual Line Touch Concept prevent false direction flips? expand_more

Once a tracked vehicle's bounding box touches its first virtual line (ENTRY_LINE or EXIT_LINE), the system sets first_crossed_line and locks the movement direction (FIRST_LINE_LOCK = True). As the bus proceeds and touches the second line, the state is already immutable, completely eliminating directional flip-flops.

Why is OCR triggered only after the first virtual line is touched? expand_more

Running deep neural OCR on every full-resolution video frame wastes GPU and CPU cycles. By activating the OCR pipeline (OCR_AFTER_FIRST_LINE_ONLY = True) only during a 4.0-second window after virtual line touch, INOUTX maximizes frame rate and processes crops only when the bus is in optimal camera focus.

What happens if an unregistered or non-college bus passes through? expand_more

The YOLO detector classifies the object as a bus, but when PaddleOCR extracts the plate and queries the MongoDB Atlas college_buses collection, the query returns no matching active pass. The vehicle is recorded into the visitor_vehicles / unverified log for security oversight.

How are virtual lines calibrated for new campus camera positions? expand_more

INOUTX includes an interactive OpenCV calibration script (calibrate_lines.py) allowing administrators to click and drag line endpoints directly on the camera preview feed. Coordinates are saved to lines_config.json and reloaded on the fly without restarting the service.
